Overview

BusinessOS is a full-stack agentic CRM designed around coordinated AI work rather than a single chatbot. Six AI agents are orchestrated through DAG-based task delegation to divide work into specialized steps and coordinate execution.

Architecture

  • Frontend: React 19.
  • API layer: FastAPI.
  • Agent orchestration: Google ADK with DAG-based task delegation.
  • Model layer: Gemini 2.5.
  • Deployment: Docker and a live cloud prototype.

Security architecture

The project is designed around seven security pillars. The published architecture includes JWT authentication, role-based access control, sandboxing and multi-factor authentication, alongside additional application controls.

Why it matters

The project combines the two sides of my professional direction: enterprise software engineering and applied AI. The emphasis is not only on model capability, but also on orchestration, access control, deployment and the operational concerns that make intelligent systems usable in real products.
